# Space-Adventure
Space Adventure is a 2D arcade game developed using Python, Tkinter and Object-Oriented Programming (OOP).
The player controls a spaceship and must avoid incoming meteors while trying to achieve the highest possible score.

About the Game

The project was created to explore Python development, object-oriented programming and graphical user interface design.
Features
2D arcade gameplay.
Spaceship movement and control.
Random meteor generation.
Collision detection.
Score tracking.
Best score saving.
Graphical interface built with Tkinter.

Technologies

Python — main programming language.
Tkinter — graphical user interface.
OOP — object-oriented programming.
Random — random game events.
File Handling — saving game records.

How to Run

Install Python 3.
Clone this repository:
git clone https://github.com/YOUR-USERNAME/Space-Adventure.git
Open the project directory.
Run the main Python file:
python main.py
